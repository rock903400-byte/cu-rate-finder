# 利率線上查詢工具 (Rate Finder)

> 一站查完各銀行 / 信合社利率，長輩也能用

## 📖 背景

比較各金融機構的貸款或存款利率時，以往必須逐一瀏覽各家網站，或打電話反覆諮詢。
本工具將分散的利率資訊集中到同一頁面，輸入金額即可即時試算，並以大字體、大按鈕
設計，讓行員在櫃檯或長輩在家中都能快速找到答案。

## 🎯 給誰用

- 民眾想比較各金融機構利率
- 行員解答客戶利率諮詢
- 銀行 / 信合所提供便民工具

## ✨ 功能

- 💰 輸入金額即試算利息與方案
- 📜 集中呈現各項規則，減少諮詢時間
- 📱 大字體大按鈕，適合各年齡層
- 📱 手機友善介面
