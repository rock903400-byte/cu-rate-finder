# 利率線上查詢工具 (Rate Finder)

> 一站查完各銀行 / 信合社利率,長輩也能用

## 🎯 給誰用
- 民眾想比較各金融機構利率
- 行員解答客戶利率諮詢
- 銀行 / 信合所提供便民工具

## ✨ 功能
- 💰 輸入金額即試算利息與方案
- 📜 集中呈現各項規則,減少諮詢時間
- 📱 大字體大按鈕,適合各年齡層
- 📱 手機友善介面

- GitHub Pages 部署
